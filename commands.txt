# davor.se terminal commands
#
# HOW THIS FILE WORKS
#   == name              starts a command. Everything below it (until the
#                        next ==) is printed, line by line, when it's typed.
#   == name, alias       several names for the same command.
#   == sudo *            a trailing * matches anything after "sudo ".
#   == *                 fallback for anything unknown. Keep it last.
#
#   Lines starting with # are comments and are never printed.
#   Leading spaces are kept, so indent freely.
#
#   [label](url)         prints a clickable link, shown as [label].
#   {cmd} {args} {input} replaced with the first word, the rest, or everything typed.
#
#   @wait 600            pause for 600 ms (dramatic effect).
#   @open https://...    open a URL.
#   @clear               clear the screen.
#   @about               show the main page again.
#   @history             list commands typed so far.
#   @matrix              replay the falling characters.
#   @reboot              replay the whole boot sequence.
#
# Exact names are matched before * patterns. Matching ignores case.
